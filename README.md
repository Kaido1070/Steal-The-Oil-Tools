# STEAL THE OIL TYCOON — Community Tools

I created this site to keep the tools I use for **STEAL THE OIL TYCOON** in one place and make them available to other players.

🌐 **Live Site:** https://stealoiltools.xyz

## Tools

- **Sale Calculator** — calculate Sale Value using Oil Amount, Sell Price, Cash Boost, and Friend Boost.
- **Oil Layout / Oil per Hour** — build your full drill layout across the map's production areas and calculate your real total Oil/s.
- **Time → Oil** — choose a run time and see your starting rate, ending rate, and total Oil gained.
- **Oil → Time** — enter a Target Oil amount and see how long your current layout needs to reach it.
- **Quick Layout Compare** — save your current layout as a baseline, change the setup, and instantly see which layout is better and by how much.
- **Drill Calculator** — calculate individual drill production using Drill Tier, Production Area, drill count, run time, and supported pet boosts.
- **Drill Compare** — compare two drills using the same setup, including production over time, total Oil, footprint, and dynamic Clock Drill growth.
- **Game Database** — browse Pets, Drills, Decorations, Solar Panels, Refineries, Totems, and Lootboxes.
- **Pet Bonus Checker** — check a pet's effect at any level from 1 to 100.
- **Events** — view upcoming map events and Admin Abuse times automatically converted to your local timezone.
- **Codes** — quickly search, filter, and copy useful in-game codes.

## Oil Layout Features

The Oil Layout tool supports the map's production areas from **×1 to ×10**, all drill tiers from **Basic to Galaxy**, Mole and Fruit pet boosts, Heart Drill Likes, Weekend ×2 lobbies, and dynamic drills such as the Clock Drill.

Each large plot has its own **5×5 boundary**, so the tool checks whether your selected drills actually fit instead of only adding their total footprint.

You can also copy a plot and paste it into other empty plots to build layouts quickly.

## Quick Layout Comparison

The comparison workflow is designed to be fast:

1. Build your current layout.
2. Press **Save Current**.
3. Change the drills, tiers, pets, or layout.
4. The site instantly shows the difference between the saved setup and the current setup.

The comparison includes current Oil/s, Oil in one hour, selected run-time production, plots used, cells used, and the percentage difference.

The saved comparison baseline is stored locally in your browser so you can come back to it later.
